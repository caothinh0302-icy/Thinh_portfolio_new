PROJECT 01 / MECHATRONICS

Prosthetic Hand (Servo-Actuated)

Built & Tested

Project Overview

  • The Problem: Open-source prosthetics often leave internal servo motors exposed to mechanical stress and lack feedback for delicate object manipulation.
  • The Solution: A 3D-printed, tendon-driven prosthetic hand actuated by a single MG946R high-torque servo, featuring a custom-designed protective casing.
  • Methodology:
    - Modeled the hand guard, motor casing, and assembly constraints in SolidWorks.
    - Fabricated prototypes using FDM 3D printing.
    - Programmed a closed-loop control architecture on an Arduino Nano using Force-Sensitive Resistors (FSRs) to provide haptic feedback.
  • Results: The fabricated assembly successfully housed all motor components without restricting tendon paths. By applying Failure Mode and Effects Analysis (FMEA) to mechanical stress points, overall grip reliability improved by 33%, allowing for non-destructive object manipulation.

Demo

Next-Generation Concept (Theoretical Direction)

Research was conducted on a more advanced, machine-learning-based control scheme for future iterations:
  • Independent Actuation: Transition from a single-motor design to five independent micro-servos for per-finger control.
  • Biosignal Integration: Utilize surface EMG (sEMG) signals to detect actual muscle-activation patterns instead of relying on simple pressure thresholds.
  • Signal Processing: Implement bandpass and notch filtering on raw EMG data, followed by feature extraction (Mean Absolute Value, Waveform Length).
  • Machine Learning Classifier: Train a classifier using the extracted features to distinguish and execute specific grip types (e.g., pinch, point, full fist).
Note: This remains a researched theoretical direction; the built and tested prototype is the single-motor, FSR-based hand shown above.
